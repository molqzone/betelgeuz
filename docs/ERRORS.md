# Error catalog

Generated by `npm run gen:errors` from core and strategy error definitions. Do not edit by hand. Remediation values are stable action identifiers for frontend presentation.

| code | phase | meaning | remediation action | retriable |
| --- | --- | --- | --- | --- |
| `protocol.mismatch` | config | The frontend and core speak incompatible protocol versions. | `upgradeFrontend` | no |
| `profile.unresolved` | profile | The target profile was not found or is incomplete. | `checkProfileSettings` | no |
| `profile.unsupported-proxy` | profile | The profile uses a proxy form the transport cannot express. | `fixProxySettings` | no |
| `config.invalid` | config | A betelgeuz setting has an invalid value. | `openSettings` | no |
| `ssh.unreachable` | connect | The SSH endpoint could not be reached (timeout, refused, or unresolvable). | `checkNetworkAndSshService` | yes |
| `ssh.auth-failed` | connect | SSH authentication failed for the configured user. | `checkCredentials` | no |
| `ssh.handshake-failed` | connect | The SSH handshake failed before authentication (key exchange or key format). | `checkAlgorithms` | no |
| `ssh.hostkey-mismatch` | identity | The presented SSH host key does not match the pinned or recorded key. | `checkHostKeyPin` | no |
| `ssh.lost` | connect | An established SSH connection dropped during an operation. | `retry` | yes |
| `identity.descriptor-mismatch` | identity | The hardware descriptor does not match the pinned board identity. | `checkIdentityPins` | no |
| `identity.descriptor-timeout` | identity | Reading the hardware descriptor from the target timed out. | `retry` | yes |
| `identity.descriptor-unreadable` | identity | The target returned a hardware descriptor that could not be read. | `showLog` | no |
| `identity.instance-changed` | identity | The backend instance identity changed since the attach was created. | `rebindAttach` | no |
| `artifact.missing` | artifact | No existing artifact was found for the selected CMake target. | `buildWithCMakeTools` | no |
| `artifact.arch-mismatch` | artifact | Host-side artifact validation failed (format or architecture). | `checkArtifactToolchain` | no |
| `artifact.runtime-incompatible` | artifact | The artifact's ELF runtime requirements do not match the target. | `checkArtifactToolchain` | no |
| `artifact.runtime-probe-failed` | artifact | Reading the target runtime information for deployment failed. | `retry` | yes |
| `artifact.cmake-unavailable` | artifact | CMake Tools is not available to resolve the workspace's artifact. | `installCmakeTools` | no |
| `artifact.ambiguous` | artifact | The target produces multiple artifacts; the single-artifact rule applies in the MVP. | `deploySingleArtifact` | no |
| `strategy.unsupported-target` | inspect | The selected strategy's required target interface is unavailable. | `selectSupportedStrategy` | no |
| `deploy.busy` | deploy | Another mutating operation is running on this attach. | `retryLater` | yes |
| `deploy.cancelled` | deploy | The operation was cancelled before its commit point; the target is unchanged. | `none` | no |

| `deploy.preflight-failed` | deploy | The target destination failed deployment preflight (storage, mount, or permissions). | `checkPrivileges` | no |
| `privilege.denied` | deploy | The target account lacks the privilege required by a templated command. | `checkPrivileges` | no |
| `debug.gdbserver-missing` | debug | gdbserver is not available on the target for the debug session. | `installGdbserver` | no |
| `runtime.service-manager-missing` | lifecycle | The configured service mode has no supported service manager or unit. | `selectSupportedStrategy` | no |
| `runtime.orphan-risk` | lifecycle | The foreground process cannot be proven safe to clean up after disconnect. | `selectSupportedStrategy` | no |
| `internal.unexpected` | any | An unexpected failure occurred; carries the failed phase and the underlying cause. | `showLog` | no |

| `rproc.crashed` | lifecycle | The small core entered the crashed state; carries the kernel log tail when readable. | `restorePreviousVersion` | no |
