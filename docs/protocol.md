# Protocol reference

Generated by `cargo xtask gen-schema` from protocol and strategy contracts. Do not edit by hand.

Protocol version: `0.1.0`. Framing: JSON-RPC 2.0 with LSP-style `Content-Length` headers over stdio.

The maximum JSON body size is `16777216` bytes. Artifact contents stay on the host; the artifact record carries a local path, target name, configuration, size, content hash, and optional symbols path; the core opens that path and streams it over SFTP.
